# Fillbyte

Fillbyte builds focused software products and developer tools. Our open-source work prioritizes practical automation, explicit security boundaries, reproducible releases, and documentation that stays useful in real projects.

## Open-source projects

| --- | --- |

| [docsmoke](https://github.com/fillbyte/docsmoke) | Executable documentation smoke tests for Markdown snippets, CI pipelines, and reusable GitHub Actions. |

Learn more at [fillbyte.com](https://fillbyte.com). For project support or security reporting, use the support and security guidance in the relevant repository.
