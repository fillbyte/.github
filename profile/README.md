# Fillbyte

Fillbyte creates software that gives people and development teams more capability with less friction. We build focused products, open-source developer infrastructure, and agent-native tools across the software lifecycle.

Our work is designed to be useful in real systems: clear in scope, composable with existing tools, explicit about trust boundaries, and backed by reproducible evidence.

## Open-source ecosystem

| Project                                                    | Role                                                                                                                                                                    |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Fillbyte Skills](https://github.com/fillbyte/skills)      | Production-grade agent skills, Codex plugins, MCP servers, and developer tools for research, architecture, implementation, testing, security, operations, and delivery. |
| [Surface Audit](https://github.com/fillbyte/surface-audit) | Deterministic security smoke tests for preview, staging, and pre-deploy web surfaces.                                                                                   |
| [docsmoke](https://github.com/fillbyte/docsmoke)           | Executable documentation tests for Markdown examples, CI pipelines, and reusable GitHub Actions.                                                                        |

## How we build

- Solve a specific problem before adding abstraction.
- Prefer interoperable, inspectable building blocks over closed workflows.
- Treat tests, documentation, security boundaries, and release evidence as product features.
- State uncertainty and limitations instead of turning incomplete evidence into confidence.
- Keep open-source interfaces useful beyond any single product, platform, vendor, or framework.

Explore our work at [fillbyte.com](https://fillbyte.com). For support, contributions, or security reporting, use the guidance in the relevant repository.
